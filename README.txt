PERSONAL WEBSITE — Gemechu Moti Muleta

FILES
- index.html
- style.css
- script.js

RUN
1. Keep all three files in the same folder.
2. Double-click index.html to open it in a browser.
3. No server or framework is required.

CUSTOMIZE
1. Replace "your.email@example.com" in index.html and script.js.
2. Replace the LinkedIn/GitHub placeholders.
3. Replace the "GM" profile placeholder with a real photo if desired.
4. Add/remove projects and publications in index.html.
5. Edit colors and spacing in style.css.

CONTACT FORM
The form currently uses mailto:, so it opens the visitor's email application.
For a production website, connect it to a backend or form service.

DEPLOYMENT
The site can be deployed to GitHub Pages, Netlify, Vercel, or any normal web host.
